# YENGFX HUB Phase 1 Implementation Plan

> **For agentic workers:** Execute inline with superpowers:executing-plans. User requested continuous execution.

**Goal:** Build a secure, responsive Phase 1 demo foundation with no live trading.

**Architecture:** Next.js server-rendered private routes and PostgreSQL-backed opaque sessions. Shared UI shells render explicitly labeled static demo content.

**Tech Stack:** Next.js, React, TypeScript, Tailwind, Radix, Prisma, PostgreSQL, Vitest, Playwright, pnpm.

**Spec:** docs/superpowers/specs/2026-10-20-phase-1-design.md

## Global Constraints

- No live trading, broker passwords, fake live state or fabricated performance.
- Server authentication and database roles guard every private route.
- Test at desktop 1440, tablet 834 and phone 390.

## Review Focus

- Expired session or database failure must not admit a user.
- Registration cannot elevate role through submitted fields.
- Reset tokens expire, are single use and revoke sessions.
- Off-origin POST requests fail, including logout.
- Mobile navigation exposes all routes without overflow.
